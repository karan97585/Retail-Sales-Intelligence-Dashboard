# Retail-Sales-Intelligence-Dashboard
End-to-End Retail Sales Intelligence Dashboard using Python, PostgreSQL, SQL, DAX and Power BI.

## Dataset

This project uses the **Brazilian E-Commerce Public Dataset (Olist)**.

Dataset Source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

> Note: The `olist_geolocation_dataset.csv` file is not included in this repository due to GitHub file size limitations.



# 📊 Retail Sales Intelligence Dashboard

An end-to-end Data Analytics project built using **Python, PostgreSQL, SQL, DAX, and Power BI**. This project demonstrates the complete data analytics workflow—from raw data preprocessing to interactive business intelligence dashboards.

---

# 🚀 Project Overview

The objective of this project is to analyze retail sales data and provide meaningful business insights through interactive Power BI dashboards.

The project follows a complete data analytics pipeline:

CSV Dataset
➡ Python Data Cleaning
➡ PostgreSQL Database
➡ SQL Analysis
➡ Power BI Dashboard
➡ Business Insights

# 📂 Project Workflow

## Step 1 — Data Collection

- Imported the Retail Sales CSV dataset.

## Step 2 — Data Cleaning (Python)

Performed data preprocessing using Python.

Tasks completed:

- Removed duplicate records
- Handled missing values
- Cleaned inconsistent data
- Exported cleaned dataset

---

## Step 3 — Database (PostgreSQL)

Imported cleaned data into PostgreSQL.

Created relational database tables.

Established relationships between tables.

---

## Step 4 — SQL Analysis

Performed business analysis using SQL.

Some analyses include:

- Monthly Revenue Trend
- Top Selling Products
- Top Product Categories
- Customer Analysis
- Seller Performance
- Payment Analysis
- Delivery Performance

---

## Step 5 — Power BI Dashboard

Connected PostgreSQL with Power BI.

Created interactive dashboards using DAX Measures.
